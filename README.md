## Main Features

* **Reinforcement Learning Recommender**: Q-Learning and Epsilon-Greedy algorithms.
* **Reward System**: +1 for ratings ≥4, −1 for <4, 0 if unrated.
* **Simulation & Evaluation**: Tracks cumulative reward and exploration; plots learning curves.
* **New User Support**: Recommend the top N movies based on favorite genres.
* **Interactive Demo**: Live recommendations with feedback updating the model.
* **Customizable**: Adjustable exploration rate, learning rate, and top-N recommendations.



 Dataset link: https://www.kaggle.com/datasets/prajitdatta/movielens-100k-dataset/data
